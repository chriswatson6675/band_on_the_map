# Data Rights

Every Source must retain rights and provenance metadata so the project can distinguish permitted use from restricted or prohibited use.

## Source Rights Metadata

Each Source should record the following fields or concepts:

- source name
- source URL
- licence
- rights class
- commercial display allowed
- long-term storage allowed
- redistribution allowed
- attribution required
- terms URL
- date rights were reviewed

## Rights Classes

- GREEN — permitted for the intended use
- AMBER — limited use / partnership / contractual restrictions
- RED — not permitted for automated ingestion or intended use

## Rules

Do not scrape or ingest a source merely because its content is publicly visible.

Do not redistribute third-party data unless rights expressly allow it.

Consumer-display rights and API/data-redistribution rights are separate.

Rights metadata must never be discarded during normalisation.
