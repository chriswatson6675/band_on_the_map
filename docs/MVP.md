# MVP

The initial MVP is limited to geographic live music discovery for Portugal and Croatia.

## Countries

- Portugal
- Croatia

## Inputs

- country/area
- From date
- To date
- event type: All / Gig / Festival
- genre
- price: Any / Free / Under €20 / Under €50

## Output

- interactive geographic map
- clustered events when zoomed out
- individual event markers when zoomed in
- event detail card
- event/source/ticket link

## Out Of Scope

- user accounts
- social features
- reviews
- flights
- hotels
- our own ticket checkout
- venue dashboards
- artist dashboards
- recommendation AI
- runtime LLM calls
- external paid API product
