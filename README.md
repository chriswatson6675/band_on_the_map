# Band on the Map

Band on the Map is an incremental side-hobby project for discovering live music geographically.

The initial scope is intentionally small:

- Portugal
- Croatia
- gigs and festivals
- arbitrary From/To date search
- interactive map
- genre filtering
- price filtering
- event detail card
- source/ticket link

The project will add future countries and features gradually as the data model, ingestion approach, and product experience mature.

Band on the Map does not promise complete coverage of all live music. It aims to provide useful geographic discovery from permitted sources, with transparent provenance and scope.

## Local Development

Prerequisites:

- Node.js
- npm

Install dependencies:

```bash
npm install
```

Run the local development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
