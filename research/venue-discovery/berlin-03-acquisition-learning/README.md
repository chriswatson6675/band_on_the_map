## Structural learning

Selector-free same-origin event-link discovery composed with the existing JSON-LD path unlocked six venues. A new generic schema.org microdata path unlocked Loci Loft. ISO basic numeric offsets are now normalized by the shared JSON-LD datetime adapter. Remaining resolved-source gaps are grouped in `capability-clusters.json`; browser-dependent endpoint discovery remains explicit because no controlled browser backend was available.

## London readiness

A durable controlled-browser endpoint-resolution worker should be proven before a large autonomous London trial.
