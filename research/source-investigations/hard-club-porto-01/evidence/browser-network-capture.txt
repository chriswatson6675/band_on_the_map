CRITICAL OBSERVATION driving this investigation's key finding: this
response DIFFERS from the earlier Level 1/2 curl probes
(evidence/ajax-agenda.html, evidence/ajax-noprior.html) ONLY in that the
date field here reads "11 Set" (day + month) instead of "11 " (day only,
identical params, identical endpoint). The only variable that changed is
that this request's session had already performed a real prior page load
of /PT/agenda/ in the same cookie jar before the AJAX call was made,
exactly as an ordinary browser visit does automatically. This directly
led to the reproduction retained at evidence/ajax-agenda-session.html,
which confirms via plain (non-browser) curl that a simple two-step HTTP
flow -- GET /PT/agenda/ once to establish a PHPSESSID cookie, then GET
/include/ajax_functions.php with that same cookie and a Referer header --
reliably reproduces the full "DD Mon" date text without requiring a
persistent headless browser.
