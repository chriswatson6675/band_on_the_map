Part of `BAND-ON-THE-MAP-BARCELONA-30-VENUE-POPULATION-02`. WordPress core

documented for Marula Café, which remains un-activated for exactly this
reason; Sala Upload's own event pages, unlike Marula's, DO state the real
date as plain visible text).
