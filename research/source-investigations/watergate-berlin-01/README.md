# watergate-berlin-01

Explanatory only — `investigation.json` in this directory is authoritative.

Part of the Berlin venue-population trial (`BOTM-DIFFICULT-SOURCE-TRIAL-01`
methodology reused for Berlin). Investigates Watergate, formerly a
techno/house club in Kreuzberg, Berlin.

## Summary — this one genuinely deferred

The physical Watergate club (Falckensteinstraße 49, Kreuzberg) **closed
permanently at the end of 2024** after 22 years, independently reported by
Electronic Groove, DJ Mag, Resident Advisor News, The Quietus, and others.
Its former domain, `water-gate.de`, is still live and recently modified —
not dead or parked — but now hosts a single-page microsite titled
"WATERGATE OPEN AIR SUMMER 26" for exactly one sporadic open-air event.

That one event page's own text confirms the closure in the source's own
words: *"Anfisa Letyago returns to Watergate Open Air – after closing one
of our final club nights."* It also states the event takes place **"at
SAGE BERLIN"** — a different physical venue entirely.

There is no recurring programme, event-card template, permalink scheme, or
any structured data path to acquire — only one hand-built promo page.
Forcing a `field_assessment`/`collector_assessment` here would misrepresent
a defunct club as an active, structurally-acquirable source.

## Decision

`DEFER` — a legitimate, complete outcome per policy, not a failure. There
is genuinely no ongoing Watergate club programme to build a collector
against. If Band on the Map later wants to track the sporadic "Watergate
Open Air" brand at its current host venue, that would be a new, differently
-scoped investigation (and would likely investigate Sage Berlin as the
actual venue), not a resurrection of this one.
