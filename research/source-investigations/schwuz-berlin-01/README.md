# schwuz-berlin-01

Explanatory only — `investigation.json` in this directory is authoritative.

Part of the Berlin 30/40 venue collector-reuse trial. SchwuZ, Germany's
oldest queer club, filed for insolvency and closed its Rollbergstraße
(Neukölln) premises in November 2025. As of this investigation
(2026-08-26), its official site (`schwuz.de`) is a small static holding
page for the rebuilding association, with no JS-driven data fetching of
any kind. It lists exactly one event — a one-off house party hosted at a
different venue ("SCHWUZ in der RENATE"), already past and marked sold
out — with no id, url, or repeatable structure behind it.

Level 1 (`PASSIVE_STATIC`) was genuinely tried and found insufficient:
there is no calendar system, feed, or API to discover, and no JS bundle
exists to justify a Level 2 structural probe. Per policy, `DEFER` does not
require exhausting the escalation ladder. This is recorded as `DEFER`, a
legitimate and honest outcome — not a judgement that SchwuZ isn't a real
music venue, but that its current official web presence offers no
acquirable structured event data. Worth re-investigating once the
association re-establishes a permanent venue and/or a real programme
system.
