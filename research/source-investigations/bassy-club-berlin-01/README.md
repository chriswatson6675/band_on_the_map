# bassy-club-berlin-01

Explanatory only — `investigation.json` in this directory is authoritative.

Part of the Berlin 30/40 venue collector-reuse trial. Both natural domain
guesses for Bassy (Cowboy) Club, Prenzlauer Berg, were checked directly
and both proved NOT to be the venue's own site:

- `bassyclub.com` now serves unrelated third-party content (an
  online-gambling/VR article), almost certainly an expired-domain
  takeover.
- `bassy-club.de` is a domain-parking "this domain is for sale" placeholder
  page with an obfuscated redirect/tracking script.

Third-party discovery sources (search results, directories, ticketing
aggregators) are themselves in conflict about whether the physical venue
is still operating at all (a 2018 closure report vs. more recent listings
implying it may still run) — none of these is first-party authority for
the venue's own facts under this project's policy, and this investigation
deliberately did not treat any of them as such.

No genuine official first-party web presence could be identified.
`identity.status` is honestly `NOT_PRESENT` (an evidenced rejection of the
two checked candidates, not an unchecked absence), and the decision is
`DEFER` — a legitimate outcome, not a guess. Re-investigate if a genuine
official Bassy Club web/social presence can later be identified.
